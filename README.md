One image that sums up the world's news of **Tuesday, 17 November 2026**,
set as a newspaper front page: a lead story, five further stories and an
in-brief strip, all readable from the picture alone.

`main.py` (Python 3.13, standard library only) copies the finished poster
from `assets/entry.png` to `/output/entry.png` (or to `$MAKEFUN_OUTPUT_DIR`
outside the grader). It uses no network and writes identical bytes on every
run. It also finds the poster relative to its own location rather than
the working directory, and creates `/output` first when that folder
does not exist yet. The poster is 1024 × 1024 px PNG, 526,452 bytes.
